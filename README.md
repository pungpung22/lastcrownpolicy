# LastCrown Policy Pages

Public policy pages for LastCrown.

Recommended GitHub Pages settings:

- Source: Deploy from a branch
- Branch: `main` or `master`
- Folder: `/root`

Primary URL after GitHub Pages is enabled:

`https://pungpung22.github.io/lastcrownpolicy/privacy.html`

## Maintenance Checklist

Review and update `privacy.html` before each store submission and whenever one of these changes:

- Ad SDKs, mediation partners, consent SDKs, or ad placements.
- Firebase, analytics, crash reporting, remote config, or diagnostics usage.
- In-app purchase products, entitlement storage, subscriptions, or restore behavior.
- Account, cloud save, leaderboard, support, or data deletion features.
- Google Play Data safety answers or App Store privacy answers.
- Public support email, deletion request flow, or store listing privacy URL.
